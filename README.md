# 不動産の物件査定を自動化｜スプレッドシート × Google Apps Script

物件データの保存ファイルを投げ込むだけで、**110項目以上を自動で抜き出し → 公的な相場データを差し込み → 一覧表と1枚の査定レポートまで**を自動で作るしくみです。
不動産会社さまから **有償で受注** し、聞き取り・設計・実装・動作確認まで一人で担当しました。

> このリポジトリは **設計の考え方だけを公開した「見本版」** です。
> コード本体・項目の辞書・実データはお客様の業務資産のため非公開としています。
> 会社名・地域・金額・画面写真も掲載していません。

## 解決した課題

物件の査定に、毎回こういう手作業が発生していました。

- 物件データの保存ファイルを開いて、必要な項目を目で拾って表に写す
- 相場を調べるために、別のサイトを何度も開いて確認する
- 1件ずつレポートの形に整える

件数が増えるほど時間がかかり、写し間違いも起きやすい状態でした。

## 作ったもの

- **取り込み**：保存ファイルを投げ込むと、110項目以上を自動で抜き出してスプレッドシートに並べる
- **相場の差し込み**：国土交通省の不動産情報ライブラリのAPI（取引価格・地価公示）と地図サービスから、その物件まわりの相場を自動で引いて列に足す
- **出力**：並べ替え・絞り込みができる一覧表と、1物件ぶんの査定レポート（1枚）

## 全体の流れ

```
物件データの保存ファイル
        │
        ▼
  ① 取り込み・項目の抜き出し（110項目以上）
        │   ・項目名を鍵にして値を取る方式
        │   ・値の掃除（和暦→西暦、単位つきの文字→数値 など）
        ▼
  ② 相場の差し込み（選ばれた行だけAPIを叩く）
        │   ├─ 国土交通省 不動産情報ライブラリ（取引価格・地価公示）
        │   └─ 地図サービス（位置の特定）
        ▼
  ③ 出力
        ├─ 一覧表（並べ替え・絞り込み用）
        └─ 査定レポート（1物件1枚）
```

## 技術的に工夫したところ

### 1. 「列の位置」ではなく「項目名」で取る
保存ファイルは、出どころによって項目の並び順が変わります。
そこで **項目名の文字を見つけて、その次に来る値を取る** 方式にしました。
並び順が変わっても壊れません。同じ名前の項目が複数出る場合（交通1〜3など）は、直前の見出しで区別しています。

### 2. HTMLでも、画面をコピペした文字でも、同じ処理で通る
投入されたものに `<` が含まれていればHTMLとして読み、含まれていなければ行の並びとして読みます。
どちらも **同じ「項目名の辞書」** を使うので、お客様がどの形で渡してきても手戻りが出ません。

### 3. 「表示用」と「計算用」を1項目につき2つ持つ
価格・面積・徒歩分数・建ぺい率などは、**お客様が見慣れた表示のまま残す列**と、
**並べ替え・計算ができる数値の列**の両方を持たせています。
（和暦の日付は西暦に、「◯,◯◯◯万円」は数値に、全角の単位記号にも対応）

### 4. 実行時間の上限で止まっても、途中から再開できる
Google Apps Script には1回あたりの実行時間の上限があります。
数千件を一度に投げられても止まらないよう、**処理位置を記録しながら進め、上限に近づいたら中断 → 次の起動で続きから再開** する形にしました。
1日100件・1回30件の運用を想定しています。

### 5. 自動テストを415件そろえた
手で確かめきれない量になるため、テストを書いて毎回まとめて流せるようにしました。
